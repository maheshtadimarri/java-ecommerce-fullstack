# ShopSphere Full Stack

A full-stack e-commerce application built with Spring Boot, React, PostgreSQL, Spring Security and JWT.

## Features
- Customer and admin roles
- Product catalog with search, filtering and sorting
- Category management
- Shopping cart
- Checkout and order history
- Inventory tracking
- Admin product and order management
- Validation, exception handling and secure REST APIs
- PostgreSQL persistence with Flyway
- Docker Compose

## Stack
Java 21 · Spring Boot · Spring Security · JPA/Hibernate · PostgreSQL · React · Vite
